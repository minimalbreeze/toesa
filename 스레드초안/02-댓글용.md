# 댓글용 문장 (퇴사할게요)

## A. 다른 사람의 퇴사·회사 글에 다는 댓글

링크는 넣지 않는다. 남의 글에 링크를 달면 광고로 보이고 신고당하기 쉽다.
궁금한 사람은 프로필로 들어온다(프로필 소개에 퇴사할게요가 있다).

```
저도 매일 마음속으로 사직서 쓰다가
아예 퇴사 게임을 하나 만들었어요
꿈 자금 모아야 사직서가 통과되는 게임인데
만들고 나니 오늘은 좀 더 버틸 만하더라고요
```

```
퇴사하고 뭐 할지 정해 두셨어요?
저는 그 질문에 대답을 못 해서
게임으로 먼저 퇴사해 보는 중이에요 ㅋㅋ
```

```
오늘도 버티셨네요
퇴근하고 누구랑 밥 한 끼 하세요
그게 생각보다 오래 버티게 해 주더라고요
```

## B. 내 글(돈 안 드는 엔딩)에 달린 답글에 다는 대댓글

맞힌 사람:
```
정답! 퇴사 게임인데 퇴사 안 하는 엔딩이에요
사람 챙기면서 하면 제일 먼저 열려요
```

틀린 사람 (예: "로또", "부모님 찬스"):
```
ㅋㅋ 그것도 넣을 걸 그랬네요
정답은 사직서 찢고 계속 다니는 엔딩이에요
```

"어디서 해요?":
```
아이폰은 앱스토어에서 "퇴사할게요 오늘도 버텼다"
안드로이드·PC는 웹으로 돼요
링크는 첫 댓글에 있어요!
```
