스포츠 블로그를 쓰는 사람이 게임을 하나 만들었습니다. 이름은 퇴사할게요 : 오늘도 버텼다. 직장인이 꿈 자금을 모아야 사직서가 통과되는 픽셀 게임입니다.

만드는 것보다 앱스토어에 올리는 게 더 막막했습니다. 사업자도 없고, 앱을 올려 본 적도 없었거든요.

같은 데서 막힐 분들을 위해 막혔던 순서대로 적어 둡니다.

1. 사업자 없이도 무료 앱은 올라간다

애플 개발자 계정은 개인으로도 만들 수 있습니다(연회비가 있습니다).

다만 유료 앱이나 인앱 결제로 돈을 받으려면 계약·세금·계좌 정보를 따로 등록해야 합니다. 저는 처음엔 무료로만 내기로 했습니다.

하나 알아 둘 점이 있습니다. 개인 계정으로 내면 앱스토어 개발자 이름에 본명(영문)이 그대로 나옵니다.

2. 앱 이름이 이미 있었다

처음 정한 이름은 "퇴사할게요"였는데, 앱스토어에 같은 이름의 앱이 이미 있었습니다. 앱스토어는 같은 이름을 두 번 쓸 수 없습니다.

그래서 퇴사할게요 : 오늘도 버텼다로 등록했습니다. 홍보할 때도 앞부분만 말하면 다른 앱이 먼저 나와서, 항상 전체 이름과 링크를 같이 씁니다.

3. 맥에서 Xcode로 업로드, 키체인 창이 안 닫힐 때

빌드는 맥 미니의 Xcode에서 했습니다. Product → Archive → Distribute App → App Store Connect 순서입니다.

중간에 "codesign이 키체인에 접근하려고 합니다" 창이 계속 떠서 비밀번호를 쳐도 안 닫혔습니다. 결국 재부팅하고 터미널에서 아래 두 줄로 해결했습니다.

security unlock-keychain ~/Library/Keychains/login.keychain-db
security set-key-partition-list -S apple-tool:,apple:,codesign: -s ~/Library/Keychains/login.keychain-db

맥 로그인 비밀번호를 물어보는데, 한글 입력 상태로 치면 계속 틀립니다. 영문으로 바꾸고 치세요. 저는 이걸로 한참 헤맸습니다.

4. 심사 거절: Guideline 2.1 Information Needed

첫 심사에서 2.1 - Information Needed를 받았습니다. 앱이 잘못됐다는 게 아니라 "어떻게 돌아가는 앱인지 더 알려 달라"는 뜻입니다.

제가 한 건 두 가지입니다.

  • 화면 녹화 영상: 아이폰 화면 기록으로 첫 화면부터 주요 기능까지 찍어서 유튜브에 일부 공개로 올리고 링크를 줬습니다.
  • 영어 설명: 애플이 물어본 항목마다 번호를 붙여서 짧게 영어로 답했습니다.

답장은 App Store Connect의 앱 심사 메시지에 회신하는 방식이고, 회신 뒤에 다시 제출합니다. 그다음 심사에서 승인됐습니다.

5. 승인됐는데 검색이 안 된다 → 판매 중단 상태

승인 메일을 받고 신나서 검색했는데 아무것도 안 나왔습니다.

App Store Connect에 들어가 보니 이런 문구가 있었습니다. "App Store에서 이 앱의 판매가 중단되었습니다."

원인은 판매할 국가를 하나도 고르지 않은 것이었습니다. 승인과 출시는 별개입니다.

해결은 간단합니다.

  • 가격 및 사용 가능 여부 → 앱 사용 가능 여부 → 사용 가능 여부 관리
  • 국가를 고르고(저는 전체 175개) 저장
  • 상태가 "처리 중에서 사용 가능"으로 바뀌고, 애플 안내로는 24시간 안에 반영됩니다

저는 얼마 지나지 않아 검색에 앱이 뜨는 걸 확인했습니다.

6. 그래서 올라간 게임

퇴근 5분 전, 부장님이 다가오는 데서 시작하는 직장인 게임입니다.

퇴사하고 하고 싶은 꿈(세계 일주, 카페 창업, 경제적 자유 등)을 하나 정하고, 그 돈과 비상금을 모아야 사직서가 통과됩니다. 월세, 점심값, 세금은 진짜처럼 빠져나갑니다.

그리고 사람과 함께한 좋은 순간이 쌓이면 "오늘도 다닐게요"라는, 돈 조건이 없는 엔딩도 열립니다.

무료이고, 광고와 뽑기는 없습니다.
